# Security and Responsible Disclosure Policy

## Reporting Security Issues

Verification-First Loan Approval is an open-source research and algorithmic auditing framework. If you discover a security vulnerability or critical issue:

1. **Do not** create a public GitHub issue.
2. Report the vulnerability via [GitHub Security Advisories](https://github.com/KUBENDHIRAN-V-B/verification-first-loan-approval/security/advisories/new) or contact the maintainers directly.
3. Provide a clear description and steps to reproduce the vulnerability.

We take security and scientific integrity seriously and will respond promptly to all disclosures.
